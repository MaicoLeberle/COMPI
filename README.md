# COMPI


Originally assigned as the main project for the "*Design and Implementation of Compilers*" graduate course during my time at [FaMAF](https://www.famaf.unc.edu.ar/), **COMPI** is now the playground to my experimental implementations of compilation infrastructure and techniques.

\
**COMPI** is also the name of the language recognized by the compiler. It is a simple imperative language, similar to C or Pascal.
